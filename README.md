## 🛠️ Kurulum / Installation

Türkçe yamayı oyuna uygulamak için aşağıdaki adımları takip edin:

1. Bu depoda yer alan çeviri dosyalarını (veya Releases kısmındaki `.zip` dosyasını) bilgisayarınıza indirin.
2. Oyunun kurulu olduğu ana klasörü açın.
3. "love_angel_syndrome" isimli uygulama dosyasına basıp tüm dosyaları ayıklayın.
4. Ayıklanmış klasördeki aynı uygulama dosyasına basın ve oyunu başlatın
